These are graphic descriptions, not deciphered number values. No equivalence or numerical meaning is assigned between tall and short variants. The existing 86/87/89/95/96 query stays unchanged; the unresolved 108/110 extension in H001 revision 3.1 is not needed on this evidence. Claude's independent confirmation is requested.

The same primary source, p. 31, defines line code 0 as the only line of text on a side; 1–3 identify separate lines, and 9 indicates a field symbol with no line of text. The discovery implementation must therefore distinguish a matching two-sign **row** from a complete two-sign **face**. Site, orientation and damage must not be supplied by the third-party converter's defaults.

The frozen five-object pilot contains none of 108/110, so its transcriptions and review decisions do not change.
